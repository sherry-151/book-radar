# 約六分鐘 Demo 講稿與操作流程

這份是口述提示，請用自己的話練習。時間包含畫面操作、等待與程式解說，試錄一次後調整長度。

## 錄影前

- 啟動 `python -m streamlit run app.py`，將瀏覽器放大。
- 準備好三個程式檔，先熟悉函式的位置。
- 先測試線上更新；無法連線就使用離線範例，錄影時清楚說明。
- 開啟麥克風，關閉通知，避免錄到個人資訊。

## 0:00–0:40 主題

「我的作品是書單雷達。瀏覽排行榜時，還要逐本查看價格，所以我做了一個能依書名與預算整理書單的工具，最後也可以匯出 CSV。」

## 0:40–1:10 資料與流程

「資料來自金石堂中文書月排行榜，範圍是前 30 名。程式使用 Requests 取得 HTML，再用 BeautifulSoup 解析，清理後交給篩選函式，最後由 Streamlit 顯示。」

## 1:10–3:30 操作展示

1. 按取得／更新書單，指出擷取時間及前 30 名範圍。
2. 清空關鍵字，將預算設成 300 元，切换價格由低到高。指出每本書都符合預算，排名仍保留原榜單名次。
3. 改用「臺灣」、500 元。若榜單變動，換一個當下結果中確實存在的書名片段。
4. 輸入不存在的書名，展示空結果提示。
5. 清空關鍵字，下載 CSV，開啟檔案展示欄位。
6. 按離線範例按鈕，說明黃色提示和快照時間。

## 3:30–5:20 核心程式

- 在 `scraper.py` 展示 `parse_books`：`li.modProList` 找出商品，`.modProName a` 找書名，`.modProRank span` 找排名，`.priceset span:last-child b` 找售價。價格轉成整數，連結用來去重。
- 在 `book_utils.py` 展示 `filter_books`：不符合關鍵字就跳過；價格未知或超過預算就跳過；最後按照選定條件排序。CSV 使用 `utf-8-sig` 支援中文辨識。
- 在 `app.py` 展示按鈕與 `session_state`：保存取得的資料，修改篩選條件時不需要再次爬網站。

## 5:20–6:00 問題、限制與心得

「一開始博客來回傳 403，因此我調整資料來源。另一個實際問題是『台』與『臺』目前不會匹配。這個作品只處理單一排行榜，價格是擷取當下的標價。未來可以增加類別與搜尋字形處理。這次我學到從取得網頁、清理資料到介面展示的完整流程。」
